# Device

Este apartado es el menú de configuración y estado del propio dispositivo separado por diferentes funciones.

## Información del sistema

Muestra datos técnicos del dispositivo como la versión de firmware instalada, el chip que monta (ESP32/ESP32-S3), la memoria libre disponible y el estado de la tarjeta SD.

## Configuración de pantalla

Permite ajustar el brillo, la orientación y el tipo de display conectado al dispositivo.

## Configuración de red/AP

Permite configurar el nombre del punto de acceso que crea el propio dispositivo para su gestión, así como las credenciales de acceso a la WebUI.

## Gestión de batería

Muestra el nivel de carga actual y permite activar modos de ahorro de energía, si el hardware lo soporta.

## Actualización de firmware (OTA)

Permite actualizar el firmware del dispositivo de forma inalámbrica (Over-The-Air), sin necesidad de conectar un cable.

## Reset/Reboot

Permite reiniciar el dispositivo o restaurar la configuración de fábrica.
