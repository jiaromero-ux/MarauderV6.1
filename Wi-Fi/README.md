# Wi-Fi

Para realizar auditorias Wi-Fi y tal y como se puede observar el dispositivo posee un apartado de 'Wi-Fi', el cual, posee 4 funcionalidades, las cuales iremos desglosando a medida que vayamos avanzando. Las opciones que podemos observar son:

- **Sniffers**: también conocidos como analizador de paquetes o monitor de red son herramientas que nos permiten capturar y analizar tráfico que circula por una red.
- **Scanners**: son herramientas que nos permitirán escanear diferentes protocolos dentro de una red Wi-Fi.
- **Attacks**: nos permitirá realizar diferentes ataques Wi-Fi.
